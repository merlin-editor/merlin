The setting

On by default, as in VS Code and Sublime. Closing one tab with unsaved changes still asks, as now: hot exit is only for quitting.

When the file on disk isn't the one your changes were made to, the file says so over its text and waits. Compare opens your version beside the disk's, as Compare with Saved does. Keep Mine leaves your changes, to save over the disk's; Use the Disk's drops them.
Where the backups are
Per project, in ~/.local/share/merlin/backups/. A backup is removed once its file is saved or closed without saving.
