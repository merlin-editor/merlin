Left: a plugin's own view

The Rust plugin declares a Cargo view with where = "left" and its own icon, so it sits in the rail after the built-in views, below a thin line. The 2 is its badge (set-view-badge): crates with updates.

A view's header

Its title, then which plugin it's from. The ↻ ⇣ ⋯ buttons are the plugin's commands from [[views.toolbar]]. Rows are a tree with expanders and chips, a new node kind.

Moving it

Right-click a rail icon, or drag it, to move the view. The plugin's where is only the default; merlin remembers where you put it, per window.

Right: its own tab row

The secondary side bar gets tabs along its top instead of sharing the left rail. Chat plugins such as OpenCode and Claude Code default here. + adds one that's hidden.

What chat needs

Markdown that streams in, file chips, an edit card with Review and Apply (the diff tab you have now), and a multi-line box with Ctrl+Enter. All drawn by merlin, so it matches the window.
