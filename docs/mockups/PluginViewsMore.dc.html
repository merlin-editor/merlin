As an editor tab

where = "tab" opens the view in an editor group, so it can go side by side with code, be split or dragged like any tab, and come back next time. Here it's Claude Code before it's signed in, with the view's empty text and buttons.

In the panel

where = "bottom" adds a tab after Problems, Output and Terminal, marked with the plugin it's from. Its toolbar holds the plugin's commands and a choice; the progress bar is a node.

The manifest

[[views]] id = "chat" title = "OpenCode" icon = "icons/chat.svg" # or a glyph name where = "right" # left · right · bottom · tab empty = "Ask about this file, or @ another." [[views.toolbar]] command = "new-chat" icon = "plus"

The host calls

render-view(id) replaces render-panel; set-view-badge, focus-view. New nodes: tree rows, chips, progress, Markdown that streams, a multi-line input and file chips. A plugin with no [[views]] has no rail icon.
