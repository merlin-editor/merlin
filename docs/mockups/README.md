# Mock-ups for the bigger features

The user approved all of these on 2026-11-05 ("I love all of it"), so
they're the target look. The live canvas is
[merlin feature mock-ups](https://claude.ai/artifact/QzFdCBA1P32LckaUDc419F),
which is private to the user. These files are copies of its artboards, so
anyone can read them without access. They're static HTML at 1280×800 in
merlin's palette (`crates/app/src/theme.rs`, `DEFAULT`), with Inter for the
interface and JetBrains Mono for code. Open one in a browser to see it; the
`support.js` line only matters on the canvas.

Read the artboard before building its feature, and match it. Where the
mock-up and the window's existing drawing disagree on small things, such as
exact paddings, follow the window's existing helpers (`Frame`, `Canvas`,
`items_card` and the like) so the frame stays one style.

| File | Feature | What it shows |
|---|---|---|
| `Terminal.dc.html` | Integrated terminal | A Terminal tab in the bottom panel, beside Problems and Output. It has a toolbar (new, choose a shell, split, kill, maximise, close), split panes, and a list of sessions on the right with a coloured dot for each one's state. |
| `Language.dc.html` | Language features | Rename in an inline box over the name, with a note of how many places it changes. Code actions in a card from a lightbulb in the gutter, grouped as Quick Fix and Refactor. Inlay hints as quiet chips. The error at the end of its line, with the line tinted. Signature help as you type. |
| `References.dc.html` | Find references | A peek view that opens between lines: a preview on the left and the references grouped by file on the right. Keys: Shift+F12, F4 and Shift+F4. |
| `Git.dc.html` | Git | Source Control with a commit box, push and pull counts, Staged and Changes sections, and hunks unfolding under each file with Stage. The gutter bar opens the change in place, with Stage, Revert and arrows. Blame for the cursor's line, faint, at the end of the line. Sync counts in the status bar. |
| `Merge.dc.html` | Merge editor | Incoming and Current side by side over a Result pane, with Accept links per conflict, a count of conflicts left, and Complete Merge. Compare Files uses the top two panes. |

A failure shown under its line. A Run Task picker from `Cargo.toml`, `package.json` and `.merlin/tasks.toml`. Output in a terminal tab. |

| `Settings.dc.html` | Settings window | A Settings tab with categories (Appearance, Text Editor, Files, Keyboard Shortcuts, Plugins), search, and User and Workspace scopes. Rows with a label, a description, the TOML key and a control (switch, segmented choice, number, select), and a Modified badge. The rows come from `crates/app/src/prefs.rs`. |
| `Keys.dc.html` | Vim mode, which-key and macros | NORMAL in the status bar, a block cursor and relative line numbers. A which-key card along the bottom after a pause on a prefix. "Recording @q" while a macro records. |
| `Workspace.dc.html` | Several folders, a second window | An Explorer with a root header for each folder, each with its branch, and Add Folder. Tabs name their folder. A second window for a tab dragged out. |
| `Markdown.dc.html` | Markdown preview | A preview beside the source (Ctrl+K V) that scrolls with it, with tables and Mermaid diagrams. |

The card stays open while the pointer moves into it, Ctrl+K Ctrl+I opens it at the cursor, and long hovers scroll. |
| `Format.dc.html` | Format and format on save | The approved "Format the file Ctrl Shift I" row in the code actions card, with "Format the selection Ctrl K Ctrl F" while something is selected. | `Rename.dc.html` | Reviewing a rename first (Shift+Enter in the rename box) | A Rename tab in the bottom panel: "Rename `accent` to `base_colour` · 3 of 4 places in 2 files", Discard (Esc) and Apply (Enter). Every place by file, each with a box to leave it out, its line, and the old name struck through beside the new. Above, the chosen row's file as a read-only review diff. The status bar says what Enter and Esc do. |
| `GitSync.dc.html` | Git: syncing, discarding and blame (two artboards) | The sync button's states: Push, Pull, Sync for both, Pushing… (a click cancels) and Publish Branch, with counts from a quiet fetch every 5 minutes while focused. Git: Blame as a column beside the numbers, one entry per run of a commit, a bar tinted by age, and a hover card for the commit with Open Changes, Blame Before This and Copy Hash. |
| `Compare.dc.html` | Git: comparing side by side | The "palette.rs (changes)" tab with HEAD (read-only) on the left and the working tree (editable) on the right, filler where lines are missing, and changed words tinted. Each change has a stage box and « revert in the gap between the panes, a blue edge once staged, and − when only some lines are. Each changed line has its own box. Change 2 of 4 with arrows, Side by side or Inline (Alt+I, picked by itself below 1000 px), Stage File and Revert File. Keys: Alt+S stages, Alt+R reverts. A part-staged file shows in Staged and Changes with "2 of 4". |
| `GitFiles.dc.html` | Git: new, deleted, moved and other files | Source Control with Merge Conflicts first, then Staged and Changes. A new file opens as one green column whose line boxes stage part of it. A deleted file is struck through and opens read-only in red with Restore. A move is one row (the new name, then where it came from), with R? for a deleted and a new file merlin pairs before git can, and it opens as the usual diff, headed "Moved from palette.rs · 94% the same". Images side by side with their sizes; other binary files show only sizes; text files over 2 MB have Diff Anyway. A mode chip (644 → 755), a submodule's commits, and a conflicted file with Resolve. Ignored files stay hidden unless Show Ignored is on. |
| `MergeFlow.dc.html` | Merging and comparing files (two artboards) | A merge's banner in Source Control with Abort Merge, Merge Conflicts with how many are left in each file, and Commit Merge with git's message, waiting until none are left. A box on each conflict line in Incoming and Current to take some lines, Accept All Incoming, and an editable Result. Complete Merge with conflicts left asks first (Keep Resolving or Complete Anyway); completing stages the file and offers the next, then Commit Merge (Continue Rebase in a rebase). Below 1000 px, the Result alone with each conflict in place and Accept links, as VS Code does. Compare Files: two editable files side by side with Swap, from the palette (Compare Files…, Compare with Clipboard, Compare with Saved) or the Explorer's Select for Compare. |
| `TaskPlugins.dc.html` | Tasks and tests from plugins | Run Task with plugins' tasks grouped as Test, Build and run, and Other, each marked with its plugin's name in a blue chip; a task "in the plugin" runs the plugin's own command and answers with a notice. The Tests view with a root per source (cargo, python, jest). A plugin's tests in the gutter with ▶ Run Test, Debug and the failure under its line. The Plugins view saying what each plugin gives. The host calls for plugin authors: `set-tasks`, `set-tests`, `set-test-results`, `run-task`. |
| `HotExit.dc.html` | Hot exit | Exit quits without asking while files are unsaved, and asks as now with hot exit off. At the next start the same tabs come back with their unsaved changes, untitled files too, under a notice with Show. After a crash, a notice with Show and Discard Them. A file changed on disk while merlin was closed says so over its text, with Compare, Use the Disk's and Keep Mine. The `files.hot_exit` setting, on by default. |
| `SettingsPages.dc.html` | The Settings window's other pages (two artboards) | Appearance: colour themes as cards drawn in their own colours, previewed on the window while the pointer or arrows are on one, with Follow the system picking one for dark and one for light. Icon themes as cards, and layouts stacked with ↑, ↓ and ✕. Search across every page, grouped by page, with working controls. A row set in the workspace says what yours is, with ↺. Keyboard Shortcuts: search by name or by pressing keys (Record Keys), All, Changed, Plugins and Conflicts, and a card that catches a key or chord and says at once what else has it, with Add and Replace. Plugins: each with its switch and memory, and a page with what it's allowed, what it costs (its memory, its programs', CPU), what it adds and its own settings. A banner when settings.toml can't be read. |
| `DebugFlow.dc.html` | Debugging, filled in (two artboards) | Run and Debug before a run: Start Debugging (F5) with the chosen configuration, yours from `.merlin/launch.toml` and what plugins find. F5 the first time asks, and remembers. `launch.toml` with `build` run first and `console = "terminal"`. Building first, and a notice when the build fails. No debugger installed: the install command, Use gdb Instead, Choose the Path. Attach to Process, and what Linux's ptrace_scope refuses. A breakpoint's condition, hit count or log message in a box between the lines. Breakpoints with every kind, ones not set and why, and Stop on (panics, exceptions). | `KeysFlow.dc.html` | Vim mode, which-key and macros, filled in (two artboards) | Settings › Keyboard Shortcuts: Keymap as VS Code, Vim or Helix, the leader key, jk to leave Insert mode, yank to the clipboard, relative numbers, and the Ctrl keys merlin keeps in every mode. Helix selects first, then acts, with the same views. |
| `PaletteSearch.dc.html` | One search for everything (two artboards) | The palette as one box over commands, symbols, files and text, in sections with their best few and a "more" link, from the user's screenshot.
