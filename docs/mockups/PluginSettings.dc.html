⑂ editor-rework⊘ 0 ⚠ 2Workspace settings: .merlin/settings.toml

Settings first

A plugin's page puts Settings first, with Allowed and Adds as tabs beside it, so the page isn't mostly stats. The count beside Plugins in the nav is how many plugin settings you've changed.

Typed rows

The same rows as merlin's own settings: a choice, a list of chips, a segmented choice, a switch, a path. Each has a description and its key. Notices and Log level every plugin gets, without declaring them.

Both scopes

On the Workspace tab a row set here says so and shows yours, with ↺ Use yours. A user-only setting, like a program's path or anything secret, is greyed here and set on User.

The manifest

[settings.check-command] type = "choice" default = "check" choices = [ { value = "check", label = "cargo check" }, { value = "clippy", label = "cargo clippy" }, ] description = "What rust-analyzer runs when you save." [settings.server-path] type = "path" scope = "user-only"

on-setting-changed(key) tells the plugin, so lsp can restart its server.
