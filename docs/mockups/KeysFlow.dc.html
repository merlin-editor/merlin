: opens a line under the text, as Vim's does, with a completion card. Vim's own commands are there (:w :q :s :g :sort :noh :e), and so is every merlin command by its name, marked merlin. :s shows the change as you type, the way the rename preview does. / and ? use merlin's find bar, so matches are tinted with a count, and n and N move.
Counts, the dot and undo. 3dw, . repeats the last change, and u undoes a whole change, including what was typed in Insert mode, with merlin's undo. Text objects (ciw ci( dap vit) use the language's tree where a plugin gives one, so af and ic are a function and a class. Several cursors each follow the keys, and V-BLOCK is merlin's box select.

Macros, in Vim

NORMALRan @q 20 times · stopped early at line 140, where w had nowhere to go
qq records, q stops, @q plays, 20@q plays it 20 times and @@ plays the last again. The keys show as they're typed. A run stops at the first key that fails, as Vim's does, and says where. u undoes a whole run. A macro is a register, so "qp pastes it as text to edit, and "qy puts it back. With several cursors it plays at each.
