Themes, as cards
Each card draws its theme's own colours on a few lines of code. Arrow keys or the pointer over a card preview it on the whole window, and Esc or leaving puts yours back. A click picks it. With Follow the system on, each card says Dark or Light, and a click picks it for that one; with it off, there's one ✓. This replaces the Theme Packs side view, and the palette's Color Theme stays.
Icons and layouts
Icon themes are the same kind of card. Layouts stack, top over bottom, as theme packs do now: ↑ and ↓ reorder, ✕ takes one off, and Add a layout lists the ones not in use.

Double-click a row, or Enter on it, to give it keys. The card waits for a key, or two in a row (a chord, as Ctrl K Ctrl F is). It says at once what else has them. Add keeps the keys the command had; Replace drops them. Right-click a row for Remove Keys, Reset, and Copy Command ID.
Record Keys turns the search box into a key catcher: press Shift+F12 and the list shows what Shift+F12 runs. Conflicts lists keys that two commands have, as VS Code users have long asked for. Changed lists yours, with ↺ to go back to merlin's. Plugins lists the keys plugins added, each marked with its plugin.
Changes go to [keys] in your settings, as "ctrl+j" = "edit.rename", and work at once. A key taken off is written as "f2" = "", as it can be by hand now.
