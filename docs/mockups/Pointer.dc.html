Hold Ctrl over a name
With Ctrl held, the name under the pointer is underlined in the link colour and the pointer becomes a hand, so you see what a click does before you click. A name with no definition, such as a keyword or a number, stays as it is, and so does the arrow.
Asking costs one textDocument/definition, sent only when the pointer stops on a new name with Ctrl down and remembered for that name, so moving along a line asks nothing. Without a language server, Ctrl changes nothing.
Rest there
