A plugin's tasks join the built-in ones, grouped as Test, Build and run, or Other, each with the plugin's name as a blue chip. Most are a command line, run in a terminal tab as the others are. A task "in the plugin" runs one of the plugin's own commands instead, and says what happened in a notice.
