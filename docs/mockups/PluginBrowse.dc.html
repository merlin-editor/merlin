Browse

The second tab beside Installed, where the “no registry yet” text is now. It lists every plugin from every enabled source, A to Z, and the box filters by name and description. Each row says whether you have it: ✓ installed, update, or a greyed for 0.13 when nothing is built for this merlin.

A plugin's page

Only what the signed index says: title, name, newest version, licence, owners, repository and description. Report opens an issue on the registry from its template.

Permissions first

What installing lets it do, before anything downloads, in the words merlin plugin install uses. Anything outside the sandbox (programs, network, files) is amber. Only those plugins get the Install? card. Plugins that stay in the sandbox install on the first click.

Versions

The one Install picks is marked: the newest that isn't withdrawn or blocked and is built for this API. A withdrawn version is struck through with its reason. Older APIs are greyed.

①②③

Install, then the card for a plugin that leaves the sandbox, then progress.

Installing

Progress in the status bar, so you can leave the page. After it, the plugin loads with no restart, the row says ✓ installed, and the page turns into its Installed page.

5 · When the list can't be used

Couldn't reach the merlin registry. Showing the list from 3 days ago. Installing needs it.
Try Again
The merlin registry's list didn't pass its signature check, so merlin isn't using it. Showing the last good one, from 9 Nov.
Details
The merlin registry's list ran out on 8 Dec and hasn't been renewed. Showing it, but nothing installs from it.

A banner over the Browse list, never a notice. A list that fails a check is never used: not one that's unsigned, expired, or older than one already seen (a rollback). merlin falls back to the last good one, read-only. Details opens merlin's Output with the reason.
