The agent chat, reworked

What people use most and ask for most in agent panels (Claude Code's VS Code extension, Zed's Agent Panel, Cursor), redrawn in merlin's style. It changes the approved Agents.html and AgentUi.html where they meet: the plugin's chips move from the header into the box, an agent's modes (opencode's build and plan) get a coloured badge that tints the chat, Enter sends, steps fold, and a turn's changes stay in a bar above the box until you keep or undo them, with Keep and Undo on each change in the editor too. merlin still draws every permission card and the review. The window

Messages: yours in a tinted bubble at the right; the agent's as plain text. Zed users asked for the two to look different.

Steps fold into one line per run ("4 steps · read 2 files, edited 2, ran a command"); click to open. The running one shows what it's doing now.

Above the box: the plan, folded to the step it's on; a message you sent while it works, waiting its turn; and the files changed but not yet kept.

The box holds everything you set: the agent's mode as a coloured badge (Tab switches), what's attached, merlin's edit mode, the plugin's chips (model, thinking), how full the context is, and Send, which turns into Stop while it works.

In the editor, each change is tinted, with Undo and Keep under it, and a bar to step through changes and files. The most-wanted item in Claude Code's VS Code tracker.

Tabs get a dot: blue when an agent waits for you, amber when it finished while you were in another tab.

19 · Colours that mean the same

merlin suggests, in the plugin docs, one meaning per colour, so a badge reads the same in any agent. A plugin can still choose its own.

PURPLE  reads only: plan, read-only
BLUE  asks first: build, default, agent
GREEN  edits on its own: accept edits
ORANGE  edits and some commands: auto
RED  never asks: bypass, full access

20 · How a mode asks

With each mode, the plugin can say one of: reads only, asks first, edits on its own, edits and safe commands, never asks. merlin then shows its card for what the mode asks about, and nothing for what the agent does itself. Without it (opencode), merlin's edit pill stays.

21 · Never asks, said plainly

A mode that never asks is red, and its box carries a red line saying the agent acts without asking. Switching to it asks once per chat, as merlin's card: Let Codex run commands without asking?
