1 · A file too large to load, edited where it is
The same view as the read-only one, but typing works: no Load to Edit, and no 16 GB of memory. About 4 MB of the file is held at a time. The edits stay in memory as the view moves on, undo and all, and the rest is read from disk. The tab gets its dot like any unsaved file, and the status bar says Edited from disk where it said Read-only. The band says what it costs: plain text only, and a save that writes the whole file. ✕ hides it for this file. Deleting a selection that reaches far past the view, such as everything above the cursor, cuts the file without reading it. Undo goes back through the edits in the order they were made, anywhere in the file.

2 · Saving
Ctrl+S writes the whole file to a new one beside it, a few MB at a time, then swaps it in, as every save does, so the file is never left half written. On this machine that's about 1 GB a second. The band shows how far, with a line along its foot, and the status bar a spinner. The text can be scrolled and searched meanwhile, but not edited: typing says so. Cancel stops it and leaves the file as it was. Undo still works after saving.
