The rule

The activity rail is for places you work; Settings is where you set things up. Plugins are set up, so the Plugins side view and its rail icon go (dashed here). The rail is left for plugins' own views, below the line.

One list

Settings › Plugins is the only list, now with what each plugin does and its switch on every row, as the side view had. Browse waits for a registry; until then it says how to install with merlin plugin install.

Per workspace

The switch's menu (right-click, or ⋯) can turn a plugin off in this workspace only. The row says off here, and its page says why it isn't running.
