A channel per plugin

The picker lists merlin, then each plugin with a log, with how many lines it has. A red dot marks one with an error since you last looked. A plugin page's Output button opens its own channel.

What goes in it

log(level, text) at trace, debug, info, warn or error, and the stderr of the plugin's processes, marked stderr. A language server's panic is finally somewhere you can read it.
