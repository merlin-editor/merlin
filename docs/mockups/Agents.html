The chat

The right side bar's tab row from PluginViews: one tab per agent the plugins add. Messages stream in; thoughts fold to one line; an agent's plan shows as a list it ticks off.

What the agent did

One quiet line per step: read, edited (with +/−), ran (linked to its terminal tab). Edits go through the editor: the tinted lines on the left are an ordinary edit, so Ctrl+Z undoes them.

Asking

The permission card sits at the bottom of the chat, not over the code, and the box below waits until it's answered. Always Allow names exactly what it covers, here cargo test in this workspace.

Commands

Run in a terminal tab named for the agent, which you can watch and stop like any other.
