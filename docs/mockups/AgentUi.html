What agent plugins add to the chat

An agent plugin can shape its chat as far as it likes: things in its messages, a header of its own, its slash commands, or a whole view of its own. merlin always draws what keeps you safe: permission cards, review and revert, commands in terminal tabs. Builds on Agents.html (approved). Approved 2026-11-16.
Inside merlin's chat

1 · Its own things in a message

A message can carry panel pieces, as plugin views do: rows, buttons, a progress bar, a picture. They're drawn in merlin's style; a click goes to the plugin.

4 · Its whole interface, with merlin's cards on top

An agent can use a view of its own in place of merlin's chat, drawn as any plugin view is. When it asks to edit or run something, merlin's card comes up at the bottom of that view, marked as merlin's, so a plugin can't draw one that looks like it. Changed files still get merlin's review.
