1 · A file too large to load opens read-only
Above a share of memory (by default, a file larger than a quarter of the memory free when it opens), merlin reads the file straight from disk instead of loading it: a 14.2 GB log shows in about a tenth of a second and costs a few MB, whatever its size. The tab has a lock and a band says why, with Load to Edit… for when you need to change it; ✕ hides the band for this file. The lines are counted in the background (about 5 s for 14 GB): the status bar shows Counting lines 38%, and until then the scrollbar goes by bytes and the tab shows the size only. Plain text only: no colours, git gutter, blame, word wrap, language servers or plugins in this view. The minimap still works, from the lines on screen.
