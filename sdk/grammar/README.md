# merlin-grammar

Tree-sitter syntax highlighting helper for [Merlin](https://github.com/merlin-editor/merlin) plugins.

Provides C library headers and bindings to compile and evaluate Tree-sitter parsers targeting `wasm32-wasip2`.

## Usage

```toml
[dependencies]
merlin-plugin = "0.9.0"
merlin-grammar = "0.9.0"
```
