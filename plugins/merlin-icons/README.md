# merlin Icons

Icon packs drawn for merlin:

- **Origami**, an icon theme: folded paper in each language's colour with a
  white mark for the kind of file (code, data, text, config, shell, image,
  lock, git), and folders that fold open. `src`, `tests`, `docs`, `.git`,
  `target` and others have their own colours and marks.
- **Outline**, an icon theme: the same shapes as thin outlines in the
  colour theme's muted colour, so it suits every theme.
- **Line Icons**, a pack: only the frame's icons (the rail, title bar and
  tab bar), in thin rounded lines that follow their buttons' colours. Turn
  it on in Preferences: Theme Packs, over any icon theme.

The SVGs are drawn by `tools/make-icons.py`; change it and run it again to
redraw them, or edit the SVGs and the pack files by hand.
