# merlin Layouts

Small packs that each change one thing, to stack over any theme in
Preferences: Theme Packs, as resource packs stack:

| Pack | Changes |
|---|---|
| Compact | Shorter rows in the side bar and panel. |
| Flat | Panes edge to edge with square corners, set apart by shade. |
| Soft | Rounder islands with more room between them. |
| Large Code | The code at 15.5 points. |
| Mono Interface | The interface in the code's font (JetBrainsMono Nerd Font). |

The top pack in the list wins where two set the same thing: Flat over Soft
gives flat panes.
