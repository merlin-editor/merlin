# merlin Themes

Sixteen colour themes made for merlin's islands, after Japanese scenes
and materials, three of them light:

| Theme | | Feel |
|---|---|---|
| Sumi | 墨 ink | Nearly monochrome warm greys, one vermilion accent. |
| Nami | 波 wave | Deep indigo, dusty blues and wisteria, autumn gold. |
| Fuji | 富士 | Moonlit night blue and snow, an amber lantern. |
| Tsuki | 月 moon | Blue-grey dusk and silver. The softest contrast. |
| Sakura | 桜 | Plum shadows, soft pinks and lilac. Gentle. |
| Asagao | 朝顔 morning glory | Violet and indigo, a blue-violet accent. |
| Matcha | 抹茶 | Tatami greens, celadon, raku clay. Soft contrast. |
| Hotaru | 蛍 firefly | Night green with a yellow-green glow. |
| Momiji | 紅葉 | Autumn browns and embers, pine and plum. Warm. |
| Kitsune | 狐 fox | Warm charcoal, fox orange and cream, a sly teal. |
| Kohaku | 琥珀 amber | Honey on dark wood, little blue light. For late nights. |
| Torii | 鳥居 | Lacquer black, vermilion and gold. Dramatic. |
| Kuro | 黒 black | The clearest contrast, for bright rooms or tired eyes. |
| Yuki | 雪 snow | Light: washi paper, ink text, vermilion. |
| Kumo | 雲 cloud | Light: cool grey, slate text, a clear blue. |
| Ume | 梅 plum | Light: blush paper, plum ink. Warm. |

They follow what makes a theme comfortable for long sessions: moderate
contrast instead of white on black (text is 11:1 to 16.5:1 against the
islands), muted, mostly warm colours, comments that stay readable (at least
4.5:1), and a handful of hues for code rather than a rainbow. Kuro is there for
when more contrast helps, and Yuki, Kumo and Ume for bright rooms.

Each theme is a TOML file in `themes/`. Edit the one in use and merlin
shows the change when you save.

```sh
merlin plugin install plugins/merlin-themes
```

Then choose one with Preferences: Color Theme in the command palette.
