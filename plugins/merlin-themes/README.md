# merlin Themes

Eight themes made for merlin's islands, after Japanese scenes and
materials:

| Theme | | Feel |
|---|---|---|
| Sumi | 墨 ink | Nearly monochrome warm greys, one vermilion accent. |
| Nami | 波 wave | Deep indigo, dusty blues and wisteria, autumn gold. |
| Fuji | 富士 | Moonlit night blue and snow, an amber lantern. |
| Sakura | 桜 | Plum shadows, soft pinks and lilac. Gentle. |
| Matcha | 抹茶 | Tatami greens, celadon, raku clay. Soft contrast. |
| Momiji | 紅葉 | Autumn browns and embers, pine and plum. Warm. |
| Torii | 鳥居 | Lacquer black, vermilion and gold. Dramatic. |
| Yuki | 雪 snow | Light: washi paper, ink text, vermilion. For daytime. |

They follow what makes a theme comfortable for long sessions: moderate
contrast instead of white on black (text is 11:1 to 16:1 against the
islands), muted, mostly warm colours, comments that stay readable (at least
4.5:1), and a handful of hues for code rather than a rainbow. Yuki is there
for bright rooms.

Each theme is a TOML file in `themes/`. Edit the one in use and merlin
shows the change when you save.

```sh
merlin plugin install plugins/merlin-themes
```

Then choose one with Preferences: Color Theme in the command palette.
